# Linux Native System Components

A collection of native Linux system components demonstrating core system programming concepts.

## Process Manager

A simple demonstration of process management in Linux using native system calls.

### Features
- Process creation using fork()
- Process synchronization
- Parent-child process communication
- Process status monitoring

### Building

```bash
make
```

### Running

```bash
./bin/process_manager
```

### Requirements
- Linux operating system
- GCC compiler
- Standard C library
